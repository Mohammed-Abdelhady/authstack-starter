# Invitations Setup Guide

Used from plan 4. Today invitations are planned and cannot be selected by the generator. No invitation route, claim or mail is issued.

## Reserved settings

| Setting                 | Reservation                                                                 |
| ----------------------- | --------------------------------------------------------------------------- |
| `INVITATION_EXPIRES_IN` | Used from plan 4. Milliseconds, seven days by default. Default `604800000`. |
