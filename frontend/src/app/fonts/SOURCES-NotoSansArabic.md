# Bundled Arabic font

This is a variable font from the Google Fonts repository, downloaded on 2026-10-12 and converted from TTF to WOFF2 without subsetting. It is recorded apart from the other fonts in `SOURCES.md` so that a project without the Arabic locale drops this file together with the font.
